Paste a model link from VRoid Hub and it will be decrypted, deobfuscated and saved as a .vrm file.

Reliability note. Downloads work by reading the model preview through a Firefox profile that is signed in to hub.vroid.com, so a signed-in Firefox session is what makes extraction reliable. Without it, the Hub withholds login-gated previews and the run stops with Failed to grab the encrypted VRM; there is no workaround on this side. If that happens, sign in to hub.vroid.com in Firefox, then press Re-check in the Session panel and retry.
